# R8 — 검증과 리뷰

## 실행 결과

- 환경: Python 3.14.7, macOS. 다른 Python/운영체제 조합은 실행 검증하지 않았다.
- 명령: `python3 -m unittest discover -s tests -v`
- 결과: 26개 테스트 통과.
- `python3 scripts/harness.py --help`: 정상 동작.
- Codex/Claude CLI 옵션은 설치된 CLI의 `--help`로 확인했다.

| 실행 일관성 | 프롬프트 작성 중 또는 AI 응답 대기 중 입력이 바뀌면 응답 수락 차단 |
| 서비스 기준 | 기본 공개 범위 변경, 소유자 선택 생략, 검수 생략, free 판매 신청 권한 부여 거절 |

읽기 전용 status가 state.json을 수정하지 않는 것도 확인했다.

## 코드 검토 중 보완

- 실패 판정에 violation_count, unknown_count, return_to를 추가해 오케스트레이터가 문자열을 추측하지 않게 했다.
- AI 프롬프트 생성 전후의 입력 해시를 비교해 입력 변경과 응답의 시점 불일치를 차단했다.
- 잘못된 review 필드 타입도 예외 없이 거절 결과로 기록하도록 했다.

## 검증하지 않은 범위

- 실제 모델 API 호출과 로그인된 CLI를 통한 유료 실행은 하지 않았다. provider 연결은 대역 테스트이며 실제 모델 출력 품질은 미검증이다.
- 실제 uibowl 레퍼런스를 수집하거나 Figma 노드를 생성하지 않았다. 입력 발췌 기반 분석과 구조화 명세 계약까지만 구현했다.
- Figma 픽셀·360px 반응형·터치 영역·실제 서비스 권한·저작권은 자동 검사 대상에 포함하지 않았다.
- 승인 이름은 인증된 계정이 아니다. 로컬 감사용 기록으로만 사용한다.
- 독립 AI 판정은 오류가 있을 수 있으며, 실제 완성 시안에 대한 사람의 확인을 대체하지 않는다.

## 남은 채택 단계

R7-orchestrator-draft.md는 기존 AGENTS.md/CLAUDE.md에 넣을 수 있는 완성된 추가 문구다.
사용자가 처음 요청한 최종 문서 승인 전이므로, 루트 파일의 OMA 블록이나 기존 지침은 수정하지 않았다.
하네스 CLI는 이 문구를 루트에 추가하지 않아도 직접 실행할 수 있다.
